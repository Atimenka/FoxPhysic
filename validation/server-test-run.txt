Команды (фрагмент):

  voxphys assemble 2 -> Сборка #1: блоков 8, пропущено 0. Блоки перенесены в тело.
  voxphys disassemble 2 -> Тело #2 разобрано: блоков возвращено 8
  voxphys impulse 1 200000 200000 0 -> Импульс приложен (Н·с, НЕ м/с).
