# FoxPhys 0.1.0-alpha.7 — план и статус

Дата последнего обновления: 2026-10-13. Журнал работ: `validation/alpha.7-session-log.txt`.

Полного текста ТЗ alpha.7 в workspace нет. Список этапов взят из `docs/ROADMAP-alpha.6.md` (§2, §4) и из запросов пользователя в ходах 22–28. Приоритеты и состав — решение агента, пользователем не подтверждены, кроме явно названных пунктов.

## Итог

- Выпуск содержит **два загрузчика**: Fabric и NeoForge (`release/alpha.7/`). NeoForge больше не заглушка: общий код компилируется на Mojang-именах, сборка и smoke-тесты проходят.
- Новое в alpha.7: мягкие тела с креплением к физическим телам, ветер по погоде, таблица плотностей и хрупкости для 1060 блоков, объёмная вода SPH (ведро, команды, рендер), публичный API для модов (версия 1), выравнивание по сетке клавишей R на обоих загрузчиках.
- Игровая проверка **не выполнена** (в среде сборки нет клиента Minecraft). Ни один пункт не считается подтверждённым в игре, пока пользователь не проверит его на тестовом мире.

## Баги, исправленные в alpha.7 (ход 9–25)

| Баг | Причина | Исправление |
|---|---|---|
| Тело проваливается при скане с интервалом >1 | `scanPending` сбрасывался до появления тела в снимке; область скана не учитывала движение | Флаг держится, пока снимок не догнал; область скана расширяется по скорости и свободному падению |
| Дубликация куба при `clear` + `restore` | Блоки из сохранения не забирались из исходных клеток | `takeSavedCells` забирает блоки, только если там тот же блок |
| Потеря тела после `restore` | Устаревший снимок перезаписывал состояние после импорта; скан не запускался сразу после импорта | Пропуск устаревших снимков; `importState` ставит `scanPending` |
| Инверсия тетраэдров мягкого тела при ударе | Слишком мягкая объёмная податливость и мало итераций | Податливость и 4 итерации для rubber/jelly (`docs/SOFT.md`) |
| Гидростатика SPH | Переходный процесс принимался за неустойчивость | Тест `hydrostatic` проходит (+14 % при допуске 25 %) |

## NeoForge: состояние

- В alpha.6 NeoForge был заглушкой (общий код исключался из сборки). В alpha.7 общий код компилируется: Fabric-файлы с Yarn-именами переведены на Mojang-имена, Fabric-специфичное (миксины Sodium, `FoxPhysMod` Fabric) оставлено в `src/`.
- Различия между сборками перечислены в `docs/API.md` (события, Sodium). Функции мода одинаковы.
- Проверено: `gradlew jar sourcesJar` (NeoForge 21.1.259), API smoke, JNI smoke, нативы внутри jar совпадают с `prebuilt`.
- Не проверено: запуск клиента и сервера NeoForge в игре.

## Что остаётся

- Игровая проверка обоих загрузчиков: мягкие тела (видимость), ведро и SPH, крепление флагов, ветер, гравипушка, клавиша R, API из чужого мода.
- Производительность воды: пул 0.4 м с 600 частицами не укладывается в 20 TPS.
- Таблица плотностей: подтверждение значений или датапак от пользователя.
- Разрыв мягких тел (`tear`) и коллизии мягких тел с блоками и телами.
