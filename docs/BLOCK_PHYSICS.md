# Физические свойства блоков Minecraft 1.21.1

Источник твёрдости (`hardness`) и взрывоустойчивости (`blast`) — игра: `BlockState.getDestroySpeed` и `Block.getExplosionResistance` для состояния по умолчанию, дамп 1060 блоков (`scripts/blocks/blocks-dump.tsv`, харнесс `BlockDump`, Minecraft 1.21.1 Mojang-имена).

**Плотность и хрупкость — оценки, а не игровые данные.** В Minecraft нет свойства плотности, поэтому плотность назначена по материалу (типичные объёмные значения реальных веществ), а хрупкость — по классу материала (шкала 0…1, 1 = разлетается при ударе). Игровых данных для этих двух колонок не существует; датапак с ними найти не удалось.

Всего блоков: **1060**. Назначено по правилам: 840, по переопределению: 93, по запасному варианту: 127. Не классифицировано: 0.
